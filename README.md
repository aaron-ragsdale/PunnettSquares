# Creature Genetics Lab

An interactive Punnett square playground where students explore inheritance by breeding fictional creatures, one trait at a time.

**[Launch the lab](https://aaron-ragsdale.github.io/PunnettSquares/)** (requires GitHub Pages to be enabled).

## What students can explore

- Customize skin appearance, horns, number of eyes, and body shape.
- Compare complete dominance, incomplete dominance, and codominance where supported by the selected trait.
- Choose parent genotypes and complete a Punnett square with immediate feedback.
- Compare predicted probabilities with simulated offspring.
- Build up inherited traits across breeding rounds. Current Parents and the offspring gallery retain previously established traits until Reset sample is selected.
- Use the Quick walkthrough for a short guided introduction.

## Classroom activity

1. Choose a trait and its inheritance rule.
2. Select the two parent genotypes.
3. Complete and check the Punnett square.
4. Breed offspring and compare observed results with predicted probabilities.
5. Repeat with another trait to build more complex creatures.

Try changing the inheritance pattern while keeping the same parental genotypes. Which probabilities change? Why might a small sample differ from the predicted ratio?

The creatures and their inheritance rules are fictional teaching models, not claims about real organisms.

## Run or remix

The entire application lives in `index.html`, including HTML, CSS, JavaScript, and SVG creature illustrations. No installation, external libraries, API keys, or backend server is required. Open the file in a browser or host it as a static website.

To publish your own version:

1. Fork this repository or upload `index.html` to a new repository.
2. Open Settings → Pages.
3. Choose Deploy from a branch, select `main` and `/ (root)`, and save.
4. Open the published URL and share it with students.

All simulation and rendering happen in the browser. The application does not require student accounts or transmit student inputs to an application backend.
